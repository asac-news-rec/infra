# infra
Infrastructure as code: Terraform and Helm charts

## 에이전트 하네스

AI 코딩 도구가 이 저장소에서 일할 때 따르는 규칙은 `AGENTS.md`와
`.claude/docs/`에 있고, 사람용 협업 규칙은 `CONTRIBUTING.md`에 있습니다.
이 규칙들은 이전 기수 팀의 [SKYAHO/Autoresearch-infra](https://github.com/SKYAHO/Autoresearch-infra)를
가져와 우리 프로젝트에 맞게 수정한 것입니다.

## 인프라 요청

인프라 자원이 필요하면 Issues → New issue → 인프라 요청 양식으로 요청합니다. Secret 값은 이슈에 적지 않습니다.
