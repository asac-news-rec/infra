# ADR-005: 인프라는 Terraform, 클러스터 안 도구는 Helm과 Argo CD(GitOps)로 관리한다

## 상태
Accepted (멘토 지시, 2026-11-03)

## 컨텍스트
인프라를 손으로 만들면 누가 무엇을 바꿨는지 기록이 없고, 계정을 바꿀 때 다시 만들기 어렵다.

## 결정
- 클라우드 리소스(버킷, 저장소, 서비스 계정, 클러스터 등)는 **Terraform**으로 만든다.
- 클러스터 안의 도구는 **Helm 차트**로 정의하고, 인프라 전용 레포를 **Argo CD**가 감시해 자동 반영한다.
- 변경은 이슈, 브랜치, PR(2명 승인)을 거친다.

## 근거
- 같은 코드로 다른 프로젝트에 재현할 수 있다(크레딧 소진 시 계정 교체).
- 모든 변경이 PR로 남아 설명과 포트폴리오 근거가 된다.

## 결과
- 상태 파일은 GCS 버킷에 저장하고 레포에는 올리지 않는다(`.gitignore`).
- 콘솔에서 손으로 바꾸면 코드와 어긋날 수 있다.

## 대안
- 콘솔에서 직접 생성: 빠르지만 기록과 재현이 어렵다.
